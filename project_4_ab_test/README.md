# 🐍 Проект 4: Изучение ошибочных ивентов в Python

## Описание проекта
Анализ A/B-теста: сравнение эффективности пуш-уведомлений и баннеров в онлайн-кинотеатре.

## Данные
- `Изучение ошибочных ивентов в Python.ipynb` — код на Python с анализом
- `Итоговаятаблица.xlsx` — итоговые данные после обработки

## Результаты
- 📊 Обработала и очистила данные о поведении пользователей за 3 месяца эксперимента
- 🔬 Провела A/B-тестирование: сравнила конверсию в покупку и средний чек между группами (баннеры vs пуши)
- 📈 Оценила статистическую значимость с помощью Pandas и SciPy
- 🎯 Сформулировала рекомендации для маркетингового отдела по выбору канала коммуникации

## Инструменты
- Python (Pandas, SciPy, Matplotlib)
- Excel
